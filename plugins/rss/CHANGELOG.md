# Changelog

## 1.0.0 — 2026-10-03

First release as a plugin. No behavior change: the `rss` poll source
(RSS 2.0 / Atom over stdlib), the trigger chip, and the chip's sample
pull (live → history → synthetic) registered exactly as before — now
from `plugins/rss/` with the plugin manifest instead of the
hand-maintained core connector lists.
