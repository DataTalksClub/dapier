Workflow automation

Connect your services. Put repeatable work on a workflow.

Dapier, a DataTalks.Club service, helps you configure workflows that respond to events and run actions across the services you connect.

How Dapier works

Choose a supported service, authorize a connection, then configure a workflow with the trigger and actions you need. Dapier uses the connected account only when a configured workflow or connection check requires it.

Connect accounts

Choose which provider account to connect and review the access requested on its consent screen.

Configure workflows

Set triggers, filters, and actions. A workflow can change data or send information to destinations you configure.

Review activity

Use run history to inspect workflow outcomes and resolve connection issues.

Google account data

When you connect a Google account, Dapier requests access needed for the operations configured for that connection. Depending on the scopes you approve, Dapier can read and download files across Drive; read, create, edit, and delete Google Docs and Sheets; check Calendar availability and edit owned events; or read YouTube channel information.

Dapier uses this data to verify the connected account and carry out workflows you configure. The current Google action catalog supports Sheets row appends; general Docs editing and Drive file watching are not yet available. Drive's read-only scope can support change notifications when a Drive watcher is added. See the Privacy Policy for storage, retention, and sharing details.

Account access

Connections are optional. You can review or revoke a connection in its provider account, or ask the Dapier operator to remove it. Dapier's use of Google account data is described in the Privacy Policy.
