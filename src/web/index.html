                        Zoom event subscription
                        
          
                        Set this Event Notification Endpoint URL in your Zoom app, select recording.completed, then click Validate in Zoom. Cloud recording must be enabled for the host.
                        
          
          
                        The connection becomes active after Zoom validates the URL. Use the zoom / recording.completed trigger in a workflow.
                        
        
                        
        
                        
          
                        Slack event subscriptions
                        
          
                        Set this Request URL in your Slack app's Event Subscriptions, subscribe to the message.channels, message.groups, message.im, message.mpim and app_mention events, then reinstall the app.
                        
          
          
          
                        Use the slack / message.received trigger in a workflow; filter on channel_id or type (e.g. app_mention).
                        
        
                        
        
                        
          
                        YouTube video push
                        
          
                        New uploads arrive as PubSubHubbub (WebSub) pushes to this callback URL:
                        
          
          
                        Subscribe the channel on the hub — pass the callback above, the topic https://www.youtube.com/xml/feeds/videos.xml?channel_id=CHANNEL_ID, and hub.secret set to the configured webhook secret:
                        
          
                        
          
                        The renewal schedule re-subscribes every channel a youtube / video.published workflow item filters on every four days, so subscriptions stay live; the manual subscribe above starts watching immediately. With a webhook secret configured, unsigned deliveries are rejected.
                        
        
                        
        
                        
          
                        Dropbox webhook
                        
          
                        Set this Webhook URI in your Dropbox app's settings (App Console → Webhooks). Dapier answers Dropbox's validation challenge.
                        
          
          
          
                        Dropbox signs every delivery with the app secret, so the secret stored for the dropbox OAuth client (Credentials, or dapier oauth-clients set dropbox) must match the App Console secret. Use the dropbox / file.created trigger (also file.updated, file.deleted) in a workflow.
