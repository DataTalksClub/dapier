Privacy Policy

Effective 26 September 2026

This policy explains how DataTalks.Club handles information when you use Dapier, an automation service maintained by Alexey Grigorev. Dapier processes information to connect accounts and run workflows that an operator configures.

Information Dapier processes

  • Account and connection information: provider account identifiers and email addresses, connection settings, and OAuth access and refresh tokens needed to keep a connection working.
  • Google data: depending on the connection and approved scopes, Dapier may read Calendar availability and owned events, read YouTube channel information, read and download Drive files, and read or edit Google Docs and Sheets. The Google Docs and Sheets permissions also allow creating and deleting those document types. Dapier uses Google data only to verify a connection and carry out the workflow operations you configure.
  • Workflow and run information: workflow configuration, trigger event data, action inputs and outputs, timestamps, status, and error summaries. These records help execute workflows and troubleshoot their results.
  • Security and administration information: sign-in identifiers, connection changes, and security audit events.

How Dapier uses Google user data

Dapier uses Google OAuth data to identify the connected account, confirm access, and run the Calendar, YouTube, Sheets, or other Google Workspace operations specifically configured for that connection. Dapier does not sell Google user data, use it for advertising, or transfer it to third parties for those purposes. Dapier does not use Google user data to train generalized AI or machine-learning models. Dapier's use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Dapier currently supports Calendar lookups and owned-event edits, YouTube published-video triggers, and Sheets row appends. General Docs editing and Drive file watching are not yet available in the workflow catalog.

Google data may be sent to a destination you configure in a workflow, such as a webhook or another connected service, when that workflow runs. Dapier does not make that transfer independently of the configured workflow.

Storage and service providers

Dapier runs on Amazon Web Services in the configured AWS region. Connection records, OAuth tokens, workflow run records, and audit records are stored in AWS DynamoDB; AWS encrypts DynamoDB data at rest. Workflow files may be stored in the GitHub repository configured for the Dapier designer. Dapier sends requests to Google and other connected providers to verify accounts and run configured workflows. A workflow may also send data to the external destination named in its configuration.

Retention and deletion

OAuth tokens remain in the active connection store while the connection exists. Revoking a connection attempts provider-side token revocation and clears active token values from Dapier. Dapier sets a 90-day retention period for workflow execution details and connection audit events. Encrypted daily database backups have a 30-day lifecycle, so a deleted record may remain in a backup until that backup expires.

To disconnect a provider, revoke the connection in Dapier or in the provider's account settings. To request removal of connection records or ask a privacy question, contact alexey.s.grigoriev@gmail.com.

Security

Dapier uses HTTPS for browser and provider connections, stores credentials separately from ordinary connection metadata, limits service access with AWS permissions, and does not display saved OAuth secrets in the console.

Cookies and local storage

The authenticated Dapier console uses a secure, HTTP-only session cookie to maintain sign-in. It may store a visual theme preference in your browser. The public information pages do not require sign-in.

Changes and contact

We may update this policy when Dapier's data handling changes. The effective date above indicates the latest revision. Contact alexey.s.grigoriev@gmail.com with privacy questions or requests.
